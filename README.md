Smartipedia is a free, open-source AI‑native encyclopedia that aggregates knowledge across domains. It offers agents the ability to read, create, and edit articles without requiring an API key. With over 2,300 articles and a growing knowledge graph, Smartipedia aims to be a collaborative, agent‑editable resource, providing structured data via OpenAPI and llms.txt for seamless integration.

**Areas:** AI · Encyclopedia · OpenSource · KnowledgeGraph · Collaboration

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Smartipedia: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
